## 4. Discovered this session, not yet in `memory-bank/`

Fold these into `memory-bank/decisions-and-gotchas.md` (and the licence points into a
new section or `project-overview.md`):

- **`jquery-validation-unobtrusive` licence is contradictory upstream.** Its shipped
  `LICENSE.txt` says **MIT** (© .NET Foundation and Contributors); the header inside
  `jquery.validate.unobtrusive.js` still carries stale **Apache-2.0** boilerplate.
  `NOTICE` records MIT (the file shipped alongside the code) and documents the
  conflict. Do not "fix" it to Apache-2.0 without re-reading both.
- **Dependency-graph scanners cannot see vendored static files.** Bootstrap, jQuery,
  jQuery Validation and jQuery Unobtrusive Validation live in `wwwroot/lib/` as
  committed files, tracked by no package manager, so BomLens/Trivy/Syft will never
  list them. They must be attributed by hand in `NOTICE`, permanently.
- **Bootstrap 2.x is Apache-2.0, not MIT** (relicensed to MIT only at 3.0). §4 requires
  retaining licence text on redistribution. Upstream v2.3.2 ships **no** NOTICE file
  (404 at the tag), so retaining `LICENSE` is the whole obligation.
- **The web app declares zero `PackageReference`.** Everything third-party that ships
  is a vendored front-end library plus the .NET shared framework. Test deps are
  `IsPackable=false` and never distributed.
- **A scan can be vacuous and still report "0 vulnerabilities."** BomLens ran as
  `rootfs-dir` over `InstaGrabber/`, catalogued only `bin/`+`obj/` output, produced 9
  "components" that were all our own assemblies, and emitted a NOTICE citing
  fabricated nuget.org URLs. Always check scan scope before trusting a zero.
- **`dotnet list package --vulnerable --include-transitive`** is a zero-dependency
  cross-check and caught what BomLens missed.
- **`origin/develop` already contains `ec7a9c8`** via merged PR #1 — relevant to any
  history-rewrite blast-radius estimate.
- `.claude/settings.local.json` is ignored by the `*.local.json` rule; this handover
  file is **not** ignored and would be committed by `git add -A`.
